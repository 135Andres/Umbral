# research/history/ — frozen records

Everything here is a FROZEN record: written once, dated, never edited afterwards except
to add a supersession pointer. It documents what was believed or done at a point in time.

It is NOT current project state. If a file here contradicts a canonical file, the
canonical file wins — that is the rule these records themselves carry.

Why it is a directory and not just a status line: two independent EXP-DOC-1 readers
reported that frozen records sitting beside living research artifacts, distinguished only
by a status line, let them reach pre-recovery answers (DOC-FRICTION-010/012). Making
history a location removes the need to read a header before trusting a file.
